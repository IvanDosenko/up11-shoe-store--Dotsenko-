# Проверка схемы именования

Все таблицы и поля названы латиницей в нижнем регистре.
Используется стиль snake_case.
Таблицы во множественном числе: roles, users, products, sizes, stock_items, orders, order_items.
Идентификаторы имеют суффикс _id: role_id, user_id, product_id и т.д.
Зарезервированные слова (order, user, size) не используются в качестве имен таблиц (использованы orders, users, sizes).
