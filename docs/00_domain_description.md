Торговая компания «Чудо Обувь» занимается продажей обуви и 
имеет сеть магазинов. Приложение для заказа обуви дает возможность 
клиентам компании выбрать и заказать одну или несколько пар обуви из 
каталога различных моделей и размеров обуви в торговом зале. На данный 
момент услуга предоставляется только для обуви, в дальнейшем возможно 
расширение ассортимента товаров за счет аксессуаров.
