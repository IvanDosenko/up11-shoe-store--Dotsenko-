**Стек технологий:** Python 3.10+, SQLite, VS Code, Git.

## Инструкция по запуску

1. Клонировать репозиторий:
   `git clone https://github.com/IvanDosenko/up11-shoe-store--Dotsenko-.git`
2. Перейти в папку проекта:
   `cd up11-shoe-store-фамилия`
3. Создать базу данных (файл появится в `db/shoe_store.sqlite`):
   `python src/db_init.py`
